Neural network from scratch

A 3-layer classifier written by hand in NumPy — forward pass, backpropagation and mini-batch gradient descent all derived manually. No PyTorch, no TensorFlow, no autograd. All 641 parameters are running in this page, in JavaScript, with no server behind it.

This is a learning project, not a medical device. It is trained on 455 cases from a single 1990s research dataset, has no clinical validation of any kind, and must not be used to make any decision about anyone's health.
